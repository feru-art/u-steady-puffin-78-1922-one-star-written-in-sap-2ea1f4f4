# One Star, Written in Sap

[![make.fun](https://make.fun/badge/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)

Entry for the make.fun bounty **One Star, Written in Sap** — a single one-line
1-star review written in the voice of a houseplant about its human owner,
under 280 characters.

`main.ts` (Node, stdlib only, no network) writes the review to
`/output/entry.txt`:

> ★☆☆☆☆ My tag says "water sparingly". He read it as a challenge and bought a bigger can. One star: I am a cactus living in a swamp of his good intentions.

Run it with:

```sh
node main.ts
```
